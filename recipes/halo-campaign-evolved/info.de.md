# Halo Campaign Evolved

Getestetes Pack: **Halo.Campaign.Evolved.Premium.Edition.MULTi13-ElAmigos** (g4u / ElAmigos).

Offline-Installer unter Proton-GE: ISO mounten → `setup.exe` → optionale nummerierte Updates.

## Quelle

- Pack-Ordner mit der ISO, **oder** die ISO direkt
- Optional unter der Quelle: `updates/1 - …/` (Auto-Erkennung)
- Oder separates Update-Feld / **Mehr → Update anwenden**

## Updates

Siehe [UPDATES.md](UPDATES.md). ElAmigos-Pakete: Ordner `1 - Halo … update …/` mit `.exe` + `elamigos-1.bin`.

## Hinweise

- ISO wird **gemountet** (kein Voll-Extract der ~66 GiB).
- Setup und Update-EXE können Wine-Fenster zeigen — Pfad im Setup ggf. manuell bestätigen.
- BYOS: Rezeptor liefert keine Download-Links — Pack-Titel unter „Wonach suchen“ im Quellen-Dialog.
